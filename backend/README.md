# KANDOR server

The KANDOR server package provides the FastAPI management plane, administrative
CLI, authentication and RBAC services, agent enrollment, heartbeat processing,
allowlisted task orchestration, audit history, and live event delivery.

KANDOR is a defensive, self-hosted security lab platform. It intentionally does
not support remote shells, arbitrary commands, uploaded executables, persistence,
or security-control evasion. See the repository-level `README.md` and `docs/`
directory for deployment, protocol, architecture, and security guidance.

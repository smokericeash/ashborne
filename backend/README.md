# ASHBORNE server

The ASHBORNE server package provides the FastAPI management plane, administrative
CLI, authentication and RBAC services, agent enrollment, heartbeat processing,
typed lab-task orchestration, audit history, and live event delivery.

ASHBORNE is an authorization-first, self-hosted adversary-emulation and pentesting
training platform. It intentionally does not support remote shells, arbitrary
commands, uploaded executables, persistence, credential collection, or
security-control evasion. See the repository-level `README.md` and `docs/`
directory for deployment, protocol, architecture, and security guidance.

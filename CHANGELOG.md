# Changelog

All notable changes follow [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and this project uses semantic versioning.

## [Unreleased]

### Planned

- External identity-provider integration and WebAuthn.

## [0.1.0] - 2026-09-13

### Added

- FastAPI management plane, PostgreSQL models/migrations, Redis coordination, JWT sessions, RBAC, audit history, enrollment, heartbeat health, allowlisted tasking, settings, SSE, CLI, and structured logging.
- Cross-platform Python diagnostic agent with secure enrollment, credential storage, retry/backoff, heartbeat, task execution, and structured results.
- React/TypeScript dark SOC console for dashboard, agents, tasks, audit, users, and settings.
- Docker Compose core and scaled demo profiles, GitHub Actions, tests, developer automation, architecture/security/deployment documentation, and a fresh-install smoke workflow.
